# Known limitations

- Manual calibration and a stationary camera are the reliable baseline. Contour detection can suggest a window, screen or wall rectangle. It needs confirmation and does not track a moving camera or detect all same-aspect framing changes.
- Quality, glare, motion, change type and empty-board detection are heuristics. Sparse content makes focus uncertain. Severe blur, hard-edged shadows, reflections, automatic white balance, low-contrast markers or compression may cause misses/false changes. Thresholds require room-specific validation.
- Person bounding boxes approximate obstruction and may include empty space. The model may miss hands, partial people and unusual poses. Fresh candidate inference blocks detected stationary people, but cannot guarantee every obstruction is detected.
- When the detector is missing, failing or deliberately disabled, automatic capture operates in an explicitly degraded motion-only mode. Unknown visibility must not be interpreted as clear. A stationary obstruction can be captured in that mode.
- A first empty board does not create a note. Clearing after writing records an event by default and updates a private comparison baseline. Incorrect borders can resemble ink; calibrate inside the writable surface.
- Comparison signals recognize visual differences, not semantic equations or diagram meaning. Localized very small changes can be missed. A cooldown introduces delay; continued writing without a pause intentionally produces fewer intermediate captures.
- Manual capture allows explicit override of quality/AI warnings. The result retains its warning measurements and manual label. Users can intentionally save duplicates manually; automatic equivalence checks still suppress them.
- EasyOCR is optional, English-only in this setup and disabled by default. It may misrecognize handwriting, mathematics, colors or diagrams. OCR recognition was not required for capture results and optional model installation is separate.
- Source frames are requested at 720p where supported; transmission is capped at 1,280 pixels wide and rectified analysis at 960. Original means the unenhanced rectified capture at that processing resolution, not a full-sensor photograph.
- Native codec availability varies. Invalid/unsupported uploads produce an error. Video upload/replay controls are supported, but unfinished replay jobs are not restored after backend restart. Existing notes remain available.
- Replay seeking preserves captured notes and starts a new run. Repeated content can be legitimately revisited after other accepted states; duplicate prevention compares with the last accepted state, not every image in all lecture history.
- One backend process and one source per session are required. At most four replay jobs run concurrently. AI inference is serialized and can reduce analysis FPS, especially during first model load. The browser preview is independent of processing cadence.
- JSON metadata is atomically replaced, but image/baseline/metadata updates are not a full database transaction. A sudden system crash can leave an orphan image, stale baseline or up to several seconds of missing statistics. Source reconnects reload the durable baseline and reset stability. Back up the sessions directory.
- Statistics count analyzed frames and reason-specific outcomes; delayed frames are not presented as finalized rejections. Manual saves intentionally increase the capture count even without a meaningful content change. Only the latest 1,000 board events are retained.
- The bundled PDF font covers common Latin/Greek text but not every writing system or mathematical glyph. Capture images preserve all visible writing independently of font support. Very long notes continue onto additional pages.
- Local origin checks and controlled file routes protect ordinary browser interactions; this is not a hardened authenticated server. Keep it bound to localhost. It does not provide multi-user access control, encryption at rest or public deployment support.
- Synthetic tests and a public-photo inference smoke check do not prove classroom accuracy. Real webcam permissions/disconnections, a still person actually blocking a physical board, lighting variability, and real-world precision/recall require a live/manual evaluation. Do not claim these are verified without carrying out that evaluation.
